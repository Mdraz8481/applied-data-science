## 🔍 Understanding the methods

This project uses specific methods to handle information. These methods produce clear results.

* Bootstrap resampling creates new sets of data to test patterns. This helps find stable answers.
* Clustering groups similar items together. This helps you discover patterns without knowing what to look for at the start.
* Data visualization turns numbers into charts. This makes information easier to read.
* Exploratory analysis looks for errors and trends in your files before you start deep work.
* Machine learning creates models that learn from your data. Use these models to make predictions about future trends.
* Natural Language Processing helps the computer understand text. Use this to analyze sentences and words.
* PCA simplifies complex data. It reduces the number of variables to make analysis manageable.
* Regression helps estimate the relationship between different numbers. This is useful for forecasting results.
* Statistics provides a way to verify if your findings are a result of chance or a real trend.
